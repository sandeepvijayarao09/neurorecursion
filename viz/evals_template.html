Methods and caveats

  • Data. Stage A uses Neuralink's 2024 compression-challenge recordings (743 channels, monkey motor cortex, mirror of the official zip). Stages B–D use the public MC_Maze dataset (DANDI 000139, 152 units, 12.9 min) because Neuralink has released no labelled data.
  • No leakage. Agents never see hand kinematics; ground truth is used only to score. In B, encoders are re-pretrained per fold on training spikes only.
  • Drift is simulated in C and D (dead channels, noisy channels, per-channel gain), on top of real within-session nonstationarity.
  • BPS is an offline proxy (Neuralink's Webgrid formula applied to reach-target selection). It is not comparable to Neuralink's closed-loop 11.32 BPS.
  • Small scale. 152 units and 13 min of pretraining data versus Neuralink's 1,024 channels and 50,000 h. Agent days use 7–8 evaluation trials each, so per-day numbers are noisy.
  • LLM agents. Section C was run before the LLM layer existed and uses the rule-based orchestrator.
