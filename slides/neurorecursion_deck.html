Recursive architecture

Three loops, each checking the one inside it

Each proposal

Act and verify

Tool agents propose a fix. A label-free verifier accepts it only if today's data improves.

Each day

Plan and check

Planner writes the day's pass/fail checks. Up to 3 loops, then done, re-plan or escalate to a human.

Each version

Rewrite and gate

Reviewer rewrites the playbook. Kept only if it wins on unseen drift scenarios.
